# AI Assistant — QA Case Study

**Type:** demonstration test design; API endpoints and contracts are illustrative, not deployed.

Focus: chat response schema, conversations, authentication, context isolation, rate limiting, invalid payloads, prompt injection, long prompts and upstream timeouts.

Import [Postman collection](postman_collection.json) and configure `{{baseUrl}}` for a test service you own or are authorized to test. You must adapt the API endpoints and assertions to its specification.

See [test cases](test-cases.md) and [test data](test-data.json).
